BrainWashed Skills

Skills teach your BrainWashed AI how to do specific jobs. Each one is a short Markdown file that people shared and a maintainer reviewed.

Install one

In the admin page open Skills, then Community. Or run brainwashed skills install <name>. You see the whole skill before it's installed.

Share yours

Press Share next to a skill in the admin page, or open a pull request here. How to write a good one.
